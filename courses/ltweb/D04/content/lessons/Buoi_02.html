🎓 Chuẩn đầu ra (CLO): CLO1 - Cài đặt, cấu hình thành thạo Web Server (XAMPP/WAMP), hiểu cơ chế biên dịch PHP, triển khai Self-hosting và kiến trúc Vibe Code.
  1. Vận dụng 3 bộ chọn CSS cơ bản (tag, .class, #id), 3 cách nhúng CSS (Inline, Internal, External), CSS Box Model (padding, border, margin) và thư viện CSS (Bootstrap, Tailwind).
  2. Giải thích được vì sao trình duyệt không hiểu trực tiếp mã PHP và vai trò của Web Server (Apache, Nginx, IIS) trong việc gọi PHP Engine biên dịch mã sang HTML.
  3. Phân biệt WAMP vs XAMPP vs MAMP, thư mục gốc htdocs (XAMPP) vs www (WAMP), và cơ chế tự động chạy tập tin mặc định index.php / index.html.
  4. Chỉnh sửa thành thạo 2 tập tin cấu hình cốt lõi: httpd.conf (đổi cổng Listen 80 sang 8080/9999 khi xung đột cổng) và php.ini (bật display_errors, tăng upload_max_filesize).
  5. Thực chiến Self-Hosting trên Windows với Ngrok (đưa localhost ra Internet thật qua 4G) và áp dụng Kiến trúc 4 ngăn khi Vibe Code với AI.

💡 Khung tư duy SCQA & Tình huống thực tế

Situation (Bối cảnh): Bạn vừa tạo xong tập tin shop.php đầu tiên có lệnh echo tính giá khuyến mãi và hào hứng nhấp đúp chuột mở trên máy tính cá nhân, rồi gửi đường dẫn http://localhost/shop/ qua Zalo cho bạn cùng bàn xem thử.
Complication (Vấn đề thực tế): Hai cú sốc xảy ra liên tiếp: (1) Nhấp đúp trực tiếp khiến trình duyệt mở bằng giao thức file:/// và phơi bày nguyên văn mã nguồn PHP chứ không tính toán; (2) Sau khi cài XAMPP chạy được http://localhost/shop/ trên máy mình, bạn cùng bàn bấm vào link đó lại báo lỗi This site can't be reached vì localhost (127.0.0.1) là vòng lặp khép kín trên từng máy riêng biệt.
Question (Câu hỏi trọng tâm): Làm thế nào để biến laptop cá nhân thành một Web Server thực thụ, cấu hình Apache/PHP không bị đụng cổng, phát sóng website ra Internet thật và tổ chức mã nguồn sạch sẽ khi dùng AI sinh code?
Answer (Giải pháp kỹ thuật): Cài đặt XAMPP, đặt mã nguồn vào C:\xampp\htdocs\, làm chủ cặp bài trùng httpd.conf & php.ini, dùng đường hầm ngược Ngrok (ngrok http 80) để public localhost ra Internet, và ép AI tuân thủ kiến trúc tách file (config.php, assets/style.css, includes/, index.php).

🗺️ Lộ trình buổi học (Mô hình 30% Đề cương - 70% Thực chiến)

Phần 1 (30% Đề cương · 75 phút)

Ôn tập CSS cốt lõi (Selector tag/.class/#id, Inline/Internal/External CSS, Box Model) + Lý thuyết Web Server (Apache, Nginx, IIS), WAMP vs XAMPP, thư mục htdocs vs www, và cấu hình httpd.conf / php.ini.

Phần 2 (70% Thực chiến Self-Hosting · 80 phút)

Giải phẫu mạng máy tính: localhost (127.0.0.1) vs LAN IP vs NAT/Firewall -> Thực hành mở đường hầm ngược với ngrok http 80 (hoặc ssh -R 80:localhost:80 nokey@localhost.run) -> Bạn cùng bàn tắt Wi-Fi dùng 4G truy cập và kiểm tra gói tin HTTP trực tiếp trên cổng 127.0.0.1:4040.

Phần 3 (70% Thực chiến Vibe Code · 95 phút)

Bắt bệnh 'Vibe Code Mì Ý' (nhét 600 dòng HTML+CSS+PHP vào 1 file) -> Thiết kế kiến trúc 4 ngăn (config.php, assets/style.css, includes/header-footer, index.php) -> Bài test bảo trì chéo trong 60 giây & Giới thiệu đề bài nâng cao cho Đồ án nhóm (VPS Ubuntu + Tailscale + Coolify).

🏠 Bài tập về nhà & Thực hành

Phần A - Câu hỏi ôn tập lý thuyết (Bám sát Giáo trình & Đề cương)

  • 2.1. Những phần mềm web server nào có thể chạy trang web viết bằng PHP? Nêu sự tương ứng giữa ngôn ngữ lập trình và web server.
  • 2.2. WAMP và XAMPP tích hợp sẵn những phần mềm nào? Điểm khác nhau giữa WAMP, MAMP và XAMPP là gì?
  • 2.3. Cổng (port) mặc định của Apache trong XAMPP là bao nhiêu? Trình bày các bước đổi sang cổng 8080 hoặc 9999 trong tập tin httpd.conf.
  • 2.4. Tập tin php.ini dùng để làm gì? Nêu ý nghĩa của thông số display_errors và upload_max_filesize.
  • 2.5. Nếu trong URL chỉ nhập tên thư mục mà không ghi tên tập tin, Apache sẽ tự động tìm tập tin nào? Điều gì xảy ra nếu thư mục đó không có tập tin mặc định?

Phần B - Bài tập thực hành Lab 3 mức độ (Cơ bản - Nâng cao - Đồ án TMĐT)

  • Mức Cơ bản (Bắt buộc - Bài 2.7 Giáo trình): Cài đặt XAMPP/WAMP, khởi động Apache + MySQL xanh lá. Tạo ltweb.php trong htdocs in ra Lập trình web PHP, truy cập qua http://localhost/ltweb.php và chụp màn hình kết quả.
  • Mức Nâng cao: Thực hành đổi cổng Apache trong httpd.conf (Listen và ServerName), bật display_errors = On trong php.ini. Tải giao diện cửa hàng tĩnh của buổi 1 vào htdocs/my_shop/ và tách CSS ra tập tin assets/style.css.
  • Mức Thử thách (Self-hosting & Kiến trúc): Dùng Ngrok phát sóng thư mục my_shop đã tách thành 4 phần (config.php, includes/header.php, includes/footer.php, index.php) lên Internet và chụp màn hình truy cập từ điện thoại 4G + giao diện localhost:4040.
