Buổi 6: Quản trị Cơ sở dữ liệu với MySQL & phpMyAdmin

CLO1, CLO2 - Thiết kế bảng CSDL quan hệ, viết thành thạo các câu lệnh SQL (DDL & DML: CREATE, SELECT, INSERT, UPDATE, DELETE, JOIN, GROUP BY) và quản trị trên phpMyAdmin.

🎯 Mục tiêu buổi học

📌 Trọng số Đề thi & Ngân hàng câu hỏi: 6/40 câu đề thi cuối kỳ (2 câu Mức 1 + 2 câu Mức 2 + 2 câu Mức 3) · 30 câu trong Ngân hàng câu hỏi.
🎓 Chuẩn đầu ra (CLO): CLO1, CLO2 - Thiết kế bảng CSDL quan hệ, viết thành thạo các câu lệnh SQL (DDL & DML: CREATE, SELECT, INSERT, UPDATE, DELETE, JOIN, GROUP BY) và quản trị trên phpMyAdmin.
  1. Hiểu rõ các khái niệm CSDL quan hệ (Bảng, Cột/Thuộc tính, Dòng/Bản ghi) và các ràng buộc toàn vẹn: PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, AUTO_INCREMENT.
  2. Sử dụng nhóm lệnh DDL (CREATE DATABASE, DROP DATABASE, CREATE TABLE, ALTER TABLE, DROP TABLE) và chọn đúng kiểu dữ liệu MySQL (varchar, text, int, float/double, date/datetime).
  3. Viết chính xác câu lệnh truy vấn SELECT theo đúng thứ tự mệnh đề bắt buộc: SELECT -> FROM -> WHERE -> GROUP BY -> HAVING -> ORDER BY -> LIMIT.
  4. Phân biệt và vận dụng kết nối bảng INNER JOIN, LEFT JOIN, RIGHT JOIN, các hàm tổng hợp (COUNT, SUM, AVG, MIN, MAX) và các lệnh INSERT INTO, UPDATE ... SET ... WHERE, DELETE FROM ... WHERE.
  5. Sử dụng thành thạo công cụ phpMyAdmin để tạo CSDL (bảng mã utf8mb4_unicode_ci), quản lý bảng, chạy truy vấn SQL và sao lưu/phục hồi (Export / Import tập tin .sql).

💡 Khung tư duy SCQA & Tình huống thực tế

Situation (Bối cảnh): Ở Chương 3, danh sách sản phẩm và giỏ hàng của bạn được lưu trong mảng PHP ($products = [...]).
Complication (Vấn đề thực tế): Biến và mảng trong PHP chỉ sống tạm thời trong bộ nhớ RAM vài mili-giây khi trang web đang chạy. Ngay khi trang tải xong, mọi dữ liệu biến mất; khách hàng đăng ký tài khoản hay đặt hàng xong đều không thể lưu lại lâu dài. Hơn nữa, khi có hàng chục ngàn đơn hàng, việc lọc và thống kê bằng mảng PHP sẽ làm treo máy chủ.
Question (Câu hỏi trọng tâm): Hệ thống nào giúp lưu trữ dữ liệu bền vững trên đĩa cứng, đảm bảo tính toàn vẹn giữa Khách hàng - Sản phẩm - Đơn hàng và truy xuất hàng vạn bản ghi trong chớp mắt?
Answer (Giải pháp kỹ thuật): Hệ quản trị cơ sở dữ liệu quan hệ MySQL kết hợp ngôn ngữ truy vấn SQL và công cụ quản trị trực quan phpMyAdmin.
