🎓 Chuẩn đầu ra (CLO): CLO1, CLO2 - Kết nối PHP với MySQL bằng thư viện MySQLi, thực thi truy vấn đọc/ghi dữ liệu động, phòng chống SQL Injection bằng Prepared Statements và hoàn thiện toàn bộ Website TMĐT.
  1. Thiết lập kết nối từ PHP đến MySQL bằng thư viện MySQLi (cả phong cách hướng đối tượng new mysqli(...) và hướng thủ tục mysqli_connect(...)), kiểm tra lỗi kết nối và thiết lập bảng mã set_charset('utf8').
  2. Tổ chức mã kết nối CSDL chuẩn mực bằng cách tách riêng tập tin config.php và nạp bằng require_once.
  3. Thực hiện trọn vẹn quy trình 4 bước thao tác dữ liệu: kết nối -> thực thi câu lệnh SQL bằng $conn->query($sql) -> lấy mảng kết hợp bằng fetch_all(MYSQLI_ASSOC) / fetch_assoc() và duyệt hiển thị bằng foreach -> đóng kết nối $conn->close().
  4. Sử dụng thành thạo Prepared Statements (prepare() -> bind_param('ss', ...) -> execute()) với ký tự giữ chỗ ? để ngăn chặn triệt để lỗ hổng SQL Injection và xử lý tải tập tin (Upload ảnh sản phẩm) qua $_FILES.
  5. Hoàn thành Bài kiểm tra thực hành Giữa kỳ (20%), Báo cáo Đồ án nhóm Website TMĐT (20%) và luyện tập Đề thi thử Cuối kỳ (40 câu / 60 phút).

💡 Khung tư duy SCQA & Tình huống thực tế

Situation (Bối cảnh): Bạn đã có giao diện HTML/CSS, bộ xử lý logic PHP (Form, Session, Cookie) và cơ sở dữ liệu MySQL chứa hàng trăm sản phẩm. Nhưng hiện tại PHP và MySQL vẫn đang đứng tách biệt nhau.
Complication (Vấn đề thực tế): Nếu bạn nối chuỗi trực tiếp dữ liệu người dùng nhập từ Form vào câu lệnh SQL (ví dụ SELECT * FROM users WHERE user = '$user'), kẻ tấn công chỉ cần nhập ' OR '1'='1 là có thể đăng nhập không cần mật khẩu hoặc xóa trắng cơ sở dữ liệu (tấn công SQL Injection)!
Question (Câu hỏi trọng tâm): Làm thế nào để kết nối PHP với MySQL một cách khoa học, dễ bảo trì và bảo vệ tuyệt đối cơ sở dữ liệu trước các cuộc tấn công SQL Injection?
Answer (Giải pháp kỹ thuật): Tách cấu hình kết nối ra config.php (đặt set_charset('utf8')), sử dụng phương thức hướng đối tượng của MySQLi để hiển thị dữ liệu động (fetch_all(MYSQLI_ASSOC)) và bắt buộc dùng Prepared Statements (prepare + bind_param) cho mọi truy vấn có tham số từ người dùng.
